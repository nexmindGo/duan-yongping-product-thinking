# 段永平产品思维 Skill

> 一个基于《雪球特别版——段永平投资问答录（商业逻辑篇）》第 4 节“产品、差异化与创新”整理的开源产品决策 Skill。

**非官方社区项目。** 本项目与段永平、雪球、OPPO、vivo、Apple、步步高及其他相关个人或公司没有隶属、授权、赞助或背书关系。

## 它解决什么问题？

这个 Skill 不是“段永平语录机器人”，也不模仿段永平本人说话。

它把第 4 节里与产品相关的观点，整理成一套可以重复使用的产品决策框架，用来回答：

- 这个产品该不该做？
- MVP 应该保留什么、砍掉什么？
- 这个功能是真差异化，还是只是“不一样”？
- AI 或新技术是真的提升体验，还是为了创新而创新？
- 产品应该怎么定价？
- 已经有很多竞品了，还能不能进入？
- 为什么产品越做越复杂，却越来越没有竞争力？

默认会给出明确结论：**做 / 缩 / 先验证 / 延后 / 停止**。

## 核心思想

当前版本只聚焦第 4 节，主要整理出这些产品规则：

- 用户价值优先于技术炫技。
- 好产品要让用户更容易获得价值。
- 差异化不是“不同”，而是用户需要、竞争对手没有充分满足的东西。
- 差异化少而强，往往胜过功能多而弱。
- 聚焦能把有限资源集中到真正重要的产品体验上。
- 没有差异化，很容易走向价格竞争。
- 定价应该和给客户创造的价值相关，而不是只跟随竞品。
- 创新必须建立在消费者导向上，不要为了新而新。
- “敢为天下后”不是抄袭：需求可以等别人验证，但“后中争先”要求你有能力做得更好。
- “不为清单”是产品能力的一部分。

完整原则见 [`references/product-principles.md`](references/product-principles.md)。

## 使用方式

可以把整个仓库作为 Skill 使用，也可以直接导入发布包 `skill.zip`。

典型提示词：

```text
用段永平产品思维评估这个 SaaS 创意：
目标用户是独立开发者，场景是……
目前竞品是……
我准备做的差异化是……
价格计划是每月 19 美元。
```

```text
我有 8 个功能准备做 MVP。
请按这个 Skill 帮我砍到最核心的一两个功能，
并给出不为清单。
```

```text
竞争对手都加了 AI 助手。
判断我是否应该跟进，不要因为“AI 很火”就给建议。
```

## 默认输出结构

默认分析包含：

1. 结论
2. 用户真正需要什么
3. 真正的差异化
4. 聚焦与取舍
5. 创新与技术
6. 定价与价值（相关时）
7. 不为清单
8. 下一步
9. 使用到的原则编号

## 为什么第一版只做第 4 节？

第一版刻意保持范围小，只做产品相关能力，避免把商业模式、企业文化、品牌营销、投资等内容混在一起，导致 Skill 失焦。

未来可以在有明确来源的前提下扩展：

- 商业模式版
- 企业文化版
- 品牌与营销版
- 完整商业决策版
